# Work Packet Template

Use this shape for Ashante issues and handoffs.

## Objective
State one bounded outcome.

## Inputs
List exact repo files, source artifacts, public endpoints, fixtures or prior issue/PR references required.

## Frozen constraints
List relevant architecture invariants that this task may not reinterpret.

## Deliverables
List exact files/code/tests/docs expected.

## Acceptance evidence
State what must be executed, compared, inspected or demonstrated before the task can be accepted.

## Failure / escalation conditions
State where the agent must stop rather than guess.

## Handoff
Return changed files, commands/tests actually run, results, unresolved defects and the recommended next lane.
